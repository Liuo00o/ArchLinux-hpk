# ⚠ 本目录文件不是本项目的基线

这里放的是 **Arch Linux 主线 `linux` 包**的素材，对应内核版本 **7.2.11-arch1**。

**本项目的基线是 6.18.57**（见 `../01-基线配置/config-lts-6.18.x86_64`）。

## 为什么不能用这些文件编译 6.18

`config.x86_64` 里含有大量 7.x 才存在的配置项。把它套到 6.18 源码上执行
`make olddefconfig` 时，6.18 不认识的选项会被**静默丢弃**，最终得到一份既非
7.2 也非 6.18 官方基线的混合配置，问题难以定位。

正确做法是版本对齐：`01-基线配置/` 下那份来自 Arch **`linux-lts`** 包，
`pkgver` 恰好就是 `6.18.57`，与 kernel.org 的 longterm 版本完全一致。

## 文件清单

| 文件 | 说明 |
|---|---|
| `config.x86_64` | Arch linux 主线 7.2.11-arch1 配置（12713 行） |
| `PKGBUILD-7.2.11-arch1` | Arch linux 主线包的打包脚本，`pkgbase=linux`。文件名已加版本后缀以避免误用 |

## 保留的原因

用于对照发行版配置在两个大版本之间的演进（例如 `HZ`、`NR_CPUS`、抢占模型的取舍差异），
以及将来若决定把基线升级到 7.x 时作为参考起点。

**再次强调：不要拿本目录的文件去编译 6.18 内核。**
